# Cloud Users Guide

Everything you need to use [cloud.fx.land](https://cloud.fx.land) - manage your files, API keys, and billing without writing any code.

## What is Fx.Land Cloud?

Fx.Land Cloud is a web-based dashboard for managing decentralized storage on IPFS. You can:

- **Pin files** to IPFS with permanent storage
- **Manage API keys** for programmatic access
- **Track billing** and add credits
- **Link wallets** for automatic payments

## Getting Started

### Step 1: Sign In

1. Go to [cloud.fx.land](https://cloud.fx.land)
2. Click **Sign in with Google**
3. Authorize access to your basic profile

That's it - you're ready to use the dashboard.

### Step 2: Explore Your Dashboard

After signing in, you'll see:

| Section | What It Does |
|:--------|:-------------|
| **Dashboard** | Overview of storage usage and recent activity |
| **My Pins** | View and manage all your pinned files |
| **API Keys** | Create keys for apps and IPFS CLI |
| **Billing** | Check credits, link wallets, view transactions |

### Step 3: Pin Your First File

1. Go to **My Pins**
2. Click **Add Pin**
3. Enter a CID (Content Identifier) from IPFS
4. Click **Pin**

Your content will be queued and pinned to the network.
