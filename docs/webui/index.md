# Web Interface

**URL**: [cloud.fx.land](https://cloud.fx.land)

The Fx.Land Web Interface provides a dashboard for managing your IPFS pins, API keys, and billing.

## In This Section

- [Getting Started](getting-started/) - Sign up and first steps
- [API Keys](api-keys/) - Create and manage access tokens
- [Credits & Billing](credits/) - Storage costs and payment
- [Wallet Linking](wallets/) - Connect blockchain wallets

## Features

### Pin Management

- View all your pinned content
- See pin status (queued, pinning, pinned, failed)
- Delete pins
- Search and filter pins

### API Key Management

- Generate API keys for programmatic access
- View and copy existing keys
- Revoke compromised keys
- OAuth flow for native applications

### Billing & Credits

- View storage usage
- Check FULA credit balance
- Add credits via blockchain transfers
- View transaction history

### Wallet Integration

- Link Ethereum, Base, or SKALE wallets
- Automatic credit detection via block scanner
- Manual transaction claiming

## Authentication

The WebUI uses Google OAuth for authentication:

1. Click "Sign in with Google"
2. Authorize Fx.Land to access your basic profile
3. You're logged in and ready to use the dashboard

Your email address becomes your account identifier across all Fx.Land services.

## Free Tier

Every account includes **500 MB** of free storage with no credit card required:

- No time limit
- Full API access
- Standard pin performance

To store more than 500 MB, add FULA credits to your account.
